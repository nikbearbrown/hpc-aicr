| 11 | CONFIRMED, with a name correction | https://apptainer.org/docs/user/latest/environment_and_metadata.html ; https://apptainer.org/docs/user/latest/docker_and_oci.html | `--env NAME=VALUE` works on run/exec/shell and DOES override image ENV. Build order of the container environment: clear env (keep HOME) -> Docker/OCI ENV from the image -> %environment -> %post -> inject APPTAINERENV_ / --env / --env-file ("so they can override or modify any previous values") -> restore host variables only if not already set.
