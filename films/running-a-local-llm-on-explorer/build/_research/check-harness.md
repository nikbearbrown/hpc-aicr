## Safe on-screen wording suggestions

- Claude Code with a local backend: "works through the documented base-URL and token variables, but Anthropic does not support non-Claude models behind a gateway."
- Do not say "Claude Code needs the bare host" as a doc rule; say "the docs' examples use a bare host and Claude Code adds /v1/messages."
- Do not say the Sonnet/Opus/Haiku aliases route subagents; say ANTHROPIC_DEFAULT_HAIKU_MODEL covers background tasks and CLAUDE_CODE_SUBAGENT_MODEL covers subagents.
- Antigravity: "its documented local-model route is the Python SDK, not the IDE."
