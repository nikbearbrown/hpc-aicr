## Extra primary facts useful for the film
- AICR login is different: `ssh USERNAME@login.aicr.ai` with SSH certificate (no password), username `institutionalusername_institutioncode` (https://docs.aicr.ai/connecting/ssh/). AICR: "You cannot SSH directly to a compute node"; you may `ssh NODE_NAME` only while you have an active job there. AICR GPU partitions: rtx-devel/b200-devel 4 h; rtx-batch/b200-batch 24 h (https://docs.aicr.ai/system-description/).
- AICR container docs use `--nv` and `export APPTAINER_BIND="/scratch,/work"` (https://docs.aicr.ai/software/containers/).
- Explorer scp from login nodes is disabled; use `xfer.discovery.neu.edu` (https://rc.northeastern.edu/aicr/aicr-faq/ and https://rc-docs.northeastern.edu/en/explorer-main/datamanagement/transferringdata.html).
- Explorer docs text and RC pages were fetched with WebFetch/WebSearch and cross-read locally with curl (same pages).
